# CampusTrips

A Vercel-ready Next.js landing page and interactive MVP concept for CampusTrips — an 18+ college-student travel planning/community platform.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Push this folder to GitHub, then import the repository into Vercel. Vercel will detect Next.js automatically.
